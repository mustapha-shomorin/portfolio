# Mustapha Shomorin Portfolio

Static portfolio site for a Data Engineer.

## Local preview

Open the project root in a browser, or run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```

## GitHub Pages deployment

1. Push this project to a GitHub repository.
2. In GitHub, open the repository settings.
3. Go to Pages.
4. Set the source to `Deploy from a branch`.
5. Select the `main` branch and `/root` folder.
6. Save.

The site will be published at a URL like:

```text
https://<username>.github.io/<repo-name>/
```

## Notes

- `.nojekyll` is included so GitHub Pages does not process the site with Jekyll.
- Replace the placeholder links in `index.html` before final publishing.
